#  MazeAdventures – A Tom & Jerry Maze Game

**MazeAdventures** is a standalone Java-based mini-game where players take control of **Tom** as he navigates a procedurally generated maze to reach **Jerry**. With a charming **graphical interface**, engaging **background music**, and intelligent **maze generation and solving algorithms**, this game blends entertainment with advanced **computer science concepts** such as **pathfinding**, **multi-threading**, and **client-server communication**.  

This project was built using **Java** and **JavaFX**, incorporating efficient **maze algorithms**, **AI-driven pathfinding**, and **performance optimizations** such as **compression and caching techniques**.  

---  

##  Gameplay & Features  

- **Interactive Maze Navigation** – Guide Tom through a dynamically generated maze to find Jerry.  
- **Intuitive GUI with Background Music** – A polished **JavaFX** interface featuring engaging visuals and music to enhance the experience.  
- **Randomized Maze Generation** – Every game session presents a new maze thanks to **procedural generation techniques**.  
- **Multiple Search Algorithms** – Players can utilize different **AI pathfinding algorithms**, including:  
  - **Breadth-First Search (BFS)**  
  - **Depth-First Search (DFS)**  
  - **Best-First Search (Greedy Algorithm)**  
- **Maze Compression & Caching** – Efficient storage and retrieval of maze data using **compression techniques** to optimize performance.  
- **Client-Server Architecture** – A **multi-threaded server** processes maze-related requests, improving responsiveness.  
- **Multi-Threaded Execution** – Ensures smooth gameplay, UI responsiveness, and fast algorithm execution.  
- **Unit Testing for Reliability** – Comprehensive **JUnit tests** ensure robustness of the game's logic and algorithms.  

---  

##  Technologies Used  

- **Java (JDK 17+)** – Core language used for development.  
- **JavaFX** – GUI framework for interactive menus and game visuals.  
- **Multi-threading** – Efficient handling of computations and server requests.  
- **Data Compression** – Reducing maze storage size for optimized performance.  
- **Caching Solutions** – Storing previously solved mazes to enhance efficiency.  
- **JUnit** – Unit testing framework to ensure code reliability.  

---  

##  Installation & Usage  

### Prerequisites  
- Java JDK (17 or later) installed.  

### Running the Game  
1. Download the **MazeAdventures.jar** file from the repository.  
2. Open a terminal or command prompt and navigate to the downloaded file’s location.  
3. Run the game using:  
   ```sh
   java -jar MazeAdventures.jar
   ```
4. Enjoy navigating through the maze as Tom to catch Jerry!
